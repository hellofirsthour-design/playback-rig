    Set

      Each song is a folder of stems, like an unzipped MultiTracks download. The app reads the Click and Guide to set up tempo and sections.

      Ending & next song

      Set once per song. Trim a track inside a block by dragging its clip's edges in the lanes; drag the small handle at a clip's top corner for a fade.

        Song details

        Grid

        If every section starts early or late by the same amount, move the grid. Sections move with it.

        Section markers

        Each section starts on a bar. Bar 1 is the first downbeat.

        Audio output

        Outputs

        Route buses, not tracks: every track goes where its bus goes. This is one setting for every song, remembered for each interface.

        Arrangement assistant (optional)

        Plain-words changes on the Edit page ("double verse 2", "cut the instrumental", "after verse 2 do chorus 2 twice then the bridge") are worked out by the app itself: free, offline, instant. You don't need a key. If you add an Anthropic API key, Claude also handles requests the app doesn't understand (about a cent each, needs the internet; it sees section names and the order, never audio).

        Updates

        Playback Rig

        Pads

        Pads are sustained tonic drones, one audio file per key (like MultiTracks pad packs). The key goes in each file's name, e.g. "A Pad.wav".

        MIDI controller

        Press Learn, then press the button (or move the fader) on your controller. Faders are the master and the buses, the way you would map them in Ableton; tracks follow their bus.

        Assigned

        New click song

        For a song without tracks: a click, plus a guide that counts you in and calls each section in the bar before it.
