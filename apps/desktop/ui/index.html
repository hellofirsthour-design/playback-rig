        Grid

        If every section starts early or late by the same amount, move the grid. Sections move with it.

        Section markers

        Audio output

        Outputs

        Route buses, not tracks: every track goes where its bus goes. This is one setting for every song, remembered for each interface.

        Arrangement assistant

        Type arrangement changes in plain words on the Edit page ("double verse 2, then go straight to the bridge"). Claude reads the request, the section names and the current order (no audio) and proposes the new order; nothing changes until you press Apply. It needs the internet and an Anthropic API key (from console.anthropic.com; each request costs a fraction of a cent). Typing a plain list (I, V1, C1 x2, B) always works, offline.

        Pads

        Pads are sustained tonic drones, one audio file per key (like MultiTracks pad packs). The key goes in each file's name, e.g. "A Pad.wav".

        Pedals and controller

        Press Learn, then the pedal or button (or move the fader). Pedal rows: tap does the first action, hold does the second.
